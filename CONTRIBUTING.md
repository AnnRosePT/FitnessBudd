# Contributing to BudgetBuddy

Thank you for your interest in contributing to BudgetBuddy!

## Development Workflow

1. **Fork and Clone**: Clone the repository to your local development machine.
2. **Branching**: Create a meaningful feature or fix branch from `main`:
   ```bash
   git checkout -b feature/my-feature-name
   ```
3. **Environment Setup**:
   - Backend: Set up Python virtual environment (`.venv`) and install dependencies from `server/requirements.txt`.
   - Frontend: Install Node dependencies using `npm install` inside `client/`.
4. **Code Quality**:
   - Maintain PEP 8 guidelines for Python code.
   - Follow clean component practices and ESLint configurations in the React client.
5. **Testing**: Run backend and frontend test suites prior to opening pull requests.
6. **Submitting Changes**: Push your branch and open a Pull Request describing your changes.
